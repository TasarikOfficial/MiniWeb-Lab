# Signal Orbit

A tiny zero-dependency interactive orbital system.

Move the pointer to subtly bend the orbit center. Click or tap anywhere in the panel to transmit an expanding signal pulse.

## Run

Open `index.html` directly in any modern browser.

## Stack

- HTML
- CSS
- Vanilla JavaScript
- No APIs, packages, build step, or runtime AI

## Interaction

- Pointer/touch movement shifts the orbital center.
- Orbiting nodes continuously animate on three tracks.
- Tap/click emits a short signal pulse.
- Responsive layout works on desktop and mobile.
