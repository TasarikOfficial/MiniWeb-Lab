# Tilt Card

A tiny zero-dependency interactive glass card that bends toward your pointer and shifts its light hotspot in real time.

## Features

- Pointer-driven 3D tilt
- Dynamic glass highlight and ambient glow
- Tap/click the card to cycle accent colors
- Center control to reset the card
- Responsive layout and reduced-motion support
- No API, packages, build step, or runtime AI

## Run

Open `index.html` directly in any modern browser.

## Demo

Move the pointer around the card. The card tilts toward the pointer while its highlight follows your position. Click/tap the card to change the accent.
