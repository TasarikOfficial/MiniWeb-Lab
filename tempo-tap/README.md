# Tempo Tap 🥁

A tiny, zero-dependency BPM detector with a bold kinetic landing screen.

## What it does

Tap/click anywhere to a beat, or press **Space** repeatedly. Tempo Tap averages the recent intervals and shows the estimated BPM. If you pause for more than 2.5 seconds, a fresh measurement begins automatically.

## Run

Open `index.html` directly in any modern browser. No install, build step, account, API, or network access is required.

## Demo / screenshot

1. Open `index.html`.
2. Tap a steady rhythm at least four times.
3. Capture the screen while the large BPM number and lime pulse are visible.

## Stack

- HTML
- CSS
- Vanilla JavaScript

Responsive for desktop and mobile, with keyboard support via the Space bar.
