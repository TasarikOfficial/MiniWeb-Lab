# Pixel Bloom ✦

A zero-dependency interactive digital garden. Click or tap anywhere on the dark canvas to grow a randomly shaped geometric flower.

## Why it is fun

- Every bloom is generated locally and looks different.
- Works with mouse, trackpad, pen, and touch via Pointer Events.
- No framework, API, account, analytics, or build step.
- Responsive editorial landing page plus an interactive canvas-like garden.

## Run

Open `index.html` in any modern browser. That's it.

## Demo / screenshots

For a clean screenshot, open the page at desktop width, plant 8–15 blooms across the garden, and capture the full page. On mobile, plant fewer larger-spaced blooms for the best composition.
