# Prism Cursor

A small pointer-reactive visual experiment built with plain HTML, CSS, and JavaScript.

## Run
Open index.html in a modern browser. No install or build step is required.

## Features
- Responsive pointer and touch interaction
- Perspective grid
- Animated geometric cursor
- No dependencies, APIs, or runtime AI

## Screenshot
Open the page full screen, move the cursor slightly away from the center, and capture the title and geometric cursor together.
