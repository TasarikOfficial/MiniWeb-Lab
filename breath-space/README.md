# Breath Space

A polished, zero-dependency 60-second guided breathing break.

## What it does

- Guides a repeating 4s inhale → 4s hold → 4s exhale rhythm
- Uses a responsive animated orb as the visual cue
- Includes pause and reset controls
- Runs for one minute and finishes automatically
- Works on desktop and mobile

## Run

Open `index.html` directly in any modern browser. No install, build step, API, account, or internet connection is required.

## Stack

Plain HTML, CSS, and JavaScript.
