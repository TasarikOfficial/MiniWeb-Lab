# Echo Ripples

A tiny, atmospheric interaction experiment: tap or click anywhere to send layered rings across a dark ambient canvas.

## Run

Open `index.html` directly in any modern browser. No install, build step, API key, network request, or dependency is required.

## Interaction

- Click/tap to create a three-wave echo.
- Drag while holding the pointer to paint a trail of echoes.
- Responsive on desktop and mobile.

## Stack

Plain HTML, CSS and JavaScript.
