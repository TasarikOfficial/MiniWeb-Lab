# Light Trails

A tiny zero-dependency canvas experiment that turns pointer movement into fading light trails.

## Features

- Smooth fading trails
- Slowly shifting colors
- Pointer and touch friendly
- Responsive full-screen layout
- No APIs, packages, build tools, or runtime AI

## Demo

Open `index.html` directly in a modern browser and move your pointer across the screen.

## Stack

Plain HTML, CSS, JavaScript, and Canvas 2D.
