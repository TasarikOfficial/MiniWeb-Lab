# Magnetic Menu 🧲

A tiny pointer-reactive navigation experiment built with plain HTML, CSS and JavaScript.

## What makes it interesting

Each oversized menu row hides a neon magnetic orb. Move your pointer across a row and the orb follows locally beneath the typography, flipping the text contrast as it passes. Tap/click a row for a short visual pulse. Keyboard focus and Enter/Space activation are supported too.

## Run

No install, build step, API key, or dependency is required.

1. Download this folder or clone MiniWeb-Lab.
2. Open `index.html` in any modern browser.
3. Move the pointer over the rows, or use touch/keyboard.

## Demo / screenshot

For a clean screenshot, use a desktop viewport around 1440×900, hover near the center of **CREATE**, and capture the full browser content area. On mobile, open the same file and swipe across a row to move the magnetic highlight.
