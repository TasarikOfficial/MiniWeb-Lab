# Kinetic Type

A tiny interactive typography experiment. Pointer movement makes the headline letters tilt and shift in 3D; the button cycles through a small set of words.

## Run

Open `index.html` directly in a modern browser. No install or build step is required.

## Stack

- HTML
- CSS
- Vanilla JavaScript
- No dependencies, APIs, analytics, or runtime AI

## Demo / screenshot

Open the page, move the pointer across the hero word, then capture the page while the letters are tilted. On touch devices the layout remains responsive and the word-switch button still works.
